- **One-line take:** The founding document. Turing dodges the unanswerable "Can machines think?" (too tied to definitions) and substitutes an **operational** question: can a machine play the *imitation game* well enough that an interrogator, communicating only by text, can't reliably tell it from a human? If behaviour is indistinguishable, withholding "thinks" is special pleading. Every later argument here (Searle, the l33t task, the understanding debate) is a *response* to this move.

- **The imitation game:** originally a man/woman guessing game; Turing swaps the machine in for one player. Crucially **text-only** — deliberately severing thinking from appearance/voice so the test targets verbal behaviour, not embodiment. His famous prediction: by ~2000, machines would fool an average interrogator ~30% of the time in 5 minutes.

- **Why it still matters — the nine objections + his replies** (this is the enduring part; he pre-empts most of the field):
  - **Theological** / **"heads in the sand"** — dismissed.
  - **Mathematical** (Gödel/Turing limits) — humans have limits too; not decisive.
  - **Argument from consciousness** (Jefferson: a machine must *feel*, not just produce symbols) — Turing notes this leads to solipsism; we grant other humans minds on behavioural grounds, so consistency demands the same for machines. *This is exactly the ground Nagel and Searle later contest.*
  - **Lady Lovelace** ("machines can only do what we tell them; no originality") — answered by *learning machines* that surprise their makers.
  - **"Informality of behaviour"** (humans aren't rule-governed) — anticipates the symbolic-vs-adaptive debate.
  - Plus continuity-of-nervous-system, ESP, etc.

- **The forward-looking core — the child machine:** Turing's real proposal isn't hand-coding an adult mind but building a **child machine** and *educating* it — learning + reward/punishment signals. He essentially sketches machine learning: don't program the answer, program the ability to acquire it. Strikingly modern.

- **Why it's foundational to this issue / to us:** it defines the *behavioural* standard the whole "do LLMs understand?" debate is fighting over — LLMs are, in a real sense, the first systems to routinely pass casual Turing tests, which is *why* the RSTA issue exists. The unresolved tension Turing bequeathed: he argues indistinguishable behaviour should *settle* the question; Searle/Nagel argue it can't. For agent work, it's the original statement of "judge by what it does" — and the reason we keep needing sharper probes (the l33t task, Othello-GPT) when raw behaviour stops being discriminating.

- **Famous line:** "We can only see a short distance ahead, but we can see plenty there that needs to be done."
