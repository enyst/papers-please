A.3     Authorship Question
Authorship question adapted from He et al. [19].
   For the next question please refer to the following definitions:
     • Sole Developer designed the logic, wrote the code, and fixed
        errors.
     • Primary Developer defined the structure and logic and sig-
        nificantly modified code included by others.
     • Secondary Developer only tweaked parameters, fixed bugs,
        or included code that was significantly modified by others.
     • Acknowledged Developer’s contribution was helpful like
        spotting a bug or suggesting a library but not fundamental
        to the final code. This would be a "Special Thanks".
     • Co-Developer is a true partnership. Both parties contributed
        roughly equally to the final functioning code.
   Imagine you were going to publish this code. Thinking only
of the code for the functions submitted; please indicate what you
think is the most accurate way to attribute authorship of the code
submitted. Remember that there are no right or wrong answers.
   Participants selected one of the following options:
     • You are the sole developer
     • You are the primary developer; Google/ChatGPT is ac-
        knowledged but not listed as a developer
     • You are the primary developer; Google/ChatGPT is the
        secondary developer
     • You and Google/ChatGPT are Co-Developers and have
        equal contribution
     • Google/ChatGPT is the primary developer; you are the
        secondary developer
     • Google/ChatGPT is the primary developer; you are ac-
        knowledged but not as a developer
     • Google/ChatGPT is the sole developer
