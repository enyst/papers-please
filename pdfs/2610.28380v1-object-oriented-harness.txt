                                         Agent harnesses are executable code that specifies the prompts, tools, and control flow around a language
                                         model. A single global harness can struggle with heterogeneous tasks that require different execution
                                         strategies. In this work, we introduce Object-Oriented Harness (OO-Harness), a harness optimization
                                         framework that evolves a hierarchy of executable harness classes using object-oriented design. During




arXiv:2610.28380v1 [cs.CL] 20 Oct 2026
                                         training, an evolution agent uses execution records to create a family of specialized harnesses, each
                                         implemented as a subclass of the base or an existing specialized harness via inheritance. At test time, a
                                         harness router uses routing lessons accumulated during training to select a specific harness for each
                                         task. Across three long-horizon benchmarks spanning business workflows, workspace tasks, and tool
                                         use, OO-Harness achieves the best performance among the compared methods, with an absolute
                                         improvement of up to 15.79% over the base harness. Extensive ablation studies examine the contributions
                                         of its core components.

Limitations
OO-Harness relies on the APIs and execution
environment provided by its host. Service out-
ages and rate limits can affect reliability, while
interface changes may require updates to evolved
harnesses. Integrating private or authenticated
services also requires secure credential handling
and permission configuration. These dependen-
cies motivate further work on robust API integra-
tion and deployment across environments.
